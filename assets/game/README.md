# Game image assets

The provided reference images selected for in-game use are stored here:

- `flight.png`: the opening flight sequence
- `ocean.png`: the sea backdrop as the Siren rises
- `siren.png`: Siren encounter and failure screen
- `siren-win.png`: victory screen
- `weapon-bowl.png`, `weapon-pink-blue.png`, `weapon-stick.png`, `weapon-swords.png`: weapon pickups and held weapons

The hamster crew is drawn in Canvas using the supplied character lineup as a style and order reference. This keeps each character clear at small mobile sizes.
