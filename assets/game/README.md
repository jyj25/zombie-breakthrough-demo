# Game image assets

Runtime image assets are grouped by use:

- `characters/`: transparent roster portraits in the supplied image's numbered 1–5 order, plus the flight intro cutout
- `enemies/`: transparent green and pink enemies
- `bosses/`: transparent Siren encounter and victory art
- `weapons/`: weapon pickups and hand-held weapon art
- `backgrounds/`: sea backdrop used during the Siren entrance
- `references/originals/`: original supplied photos and illustrations before background removal
- `references/`: supplied character lineup and crew composition references

The flight image preserves white areas inside the hand-drawn characters. The roster portraits are cropped from the supplied lineup image and sized in Canvas at runtime.
