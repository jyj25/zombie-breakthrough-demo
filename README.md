# 세이렌 토벌

모바일과 데스크톱 브라우저에서 실행되는 객체 지향 HTML5 Canvas 러너 게임입니다. 정적 파일만으로 실행되며 별도 서버 라이브러리는 필요하지 않습니다.

## 플레이

- 마우스나 손가락으로 화면을 좌우로 움직여 토벌대를 조종합니다.
- 길은 화면 너비 전체를 세 레인으로 나누며, 가운데 적 무리를 공격하고 좌우 구역에서 무기와 보너스를 고릅니다.
- 빨간 `−` 게이트는 공격력을 깎으므로 피하세요. 공격력은 최소 1을 유지합니다.
- 캐릭터는 자동으로 발사합니다. `×2`~`×5` 게이트는 한 번에 나가는 탄환 수를 늘립니다.
- 공격력 보너스와 무기를 모아 공격력을 최대 9,999까지 올립니다.
- 공격력 × 발사 배수가 12,000을 넘으면 체력 999,999인 세이렌이 등장합니다. 세이렌 등장 연출은 약 3초 동안 진행됩니다. 중간 보스는 없습니다.
- 한 탄환의 공격력 상한은 9,999, 발사 수 상한은 5입니다.
- 몬스터 무리나 세이렌이 토벌대에 닿으면 실패합니다.

## 그림 미리보기

캐릭터, 무기, 세이렌 그림은 [미리보기 페이지](./preview.html)에서 한눈에 볼 수 있습니다.

## 동료 합류 순서

치이카와가 기본 동료로 나오며, 공격력 기준에 따라 하치와레, 우사기, 랏코, 쿠리만쥬가 차례로 합류합니다. 최대 동료 수는 다섯입니다.

| 공격력 | 합류 캐릭터 |
| ---: | --- |
| 10 | 치이카와 |
| 100 | 하치와레 |
| 1,000 | 우사기 |
| 2,000 | 랏코 |
| 4,000 | 쿠리만쥬 |

토벌대 캐릭터는 제공된 2D 이미지에서 분리한 투명 PNG를 사용합니다. 원본 참고 이미지는 `assets/game/references/`에 보관하고, 투명 배경 에셋은 캐릭터·적·보스·무기별 폴더로 나누었습니다.

## 프로젝트 구조

- `src/GameController.js`: 상태 전환, 스폰, 공격, 충돌, 승패 판정
- `src/entities/`: 플레이어, 세이렌, 게이트, 무기, 몬스터, 탄환 객체
- `src/input/PointerController.js`: 마우스 및 터치 입력을 레인 위치로 변환
- `src/render/GameRenderer.js`: 배경, 캐릭터, 무기, 전투 연출 Canvas 렌더링
- `src/ui/GameUI.js`: 시작, 실패, 성공 대화상자와 HUD
- `src/config.js`: 공격력, 발사, 동료 합류 및 세이렌 설정
- `assets/game/characters/`, `enemies/`, `bosses/`, `weapons/`, `backgrounds/`: 게임에서 사용하는 분류별 이미지
- `assets/game/references/`: 제공된 원본 및 참고 이미지

새 동료 기준이나 발사 속도를 조절하려면 `src/config.js`를 수정하세요. 캐릭터 크기와 해변 연출은 `src/render/GameRenderer.js`에서 관리합니다.

## 실행 및 배포

`index.html`을 정적 호스팅에 올리면 됩니다. 로컬에서 확인할 때는 정적 웹 서버를 사용하세요. 게임은 GitHub Pages에서 공개됩니다.
