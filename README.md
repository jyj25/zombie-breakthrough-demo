# 세이렌 토벌

모바일과 데스크톱 브라우저에서 실행되는 객체 지향 HTML5 Canvas 러너 게임입니다. 정적 파일만으로 실행되며 별도 서버 라이브러리는 필요하지 않습니다.

## 플레이

- 마우스나 손가락으로 화면을 좌우로 움직여 토벌대를 조종합니다.
- 캐릭터는 자동으로 발사합니다. `×2`, `×3` 게이트는 한 번에 나가는 탄환 수를 늘립니다.
- 공격력 보너스와 무기를 모아 공격력을 최대 9,999까지 올립니다.
- 공격력 × 발사 배수가 9,999를 넘으면 체력 99,999인 세이렌이 등장합니다. 중간 보스는 없습니다.
- 한 탄환의 공격력 상한은 9,999, 발사 수 상한은 3입니다.
- 몬스터 무리나 세이렌이 토벌대에 닿으면 실패합니다.

## 동료 합류 순서

흰 햄스터가 선두에 있고, 공격력 기준에 따라 다음 동료가 한 명씩 합류합니다.

| 공격력 | 합류 캐릭터 |
| ---: | --- |
| 10 | 치이카와 |
| 100 | 하치와레 |
| 1,000 | 우사기 |
| 2,000 | 랏코 |
| 4,000 | 쿠리만쥬 |

캐릭터는 참고 이미지를 바탕으로 Canvas 벡터로 그립니다. 세이렌, 비행 오프닝, 무기, 성공 및 실패 화면은 `assets/game/`의 이미지 에셋을 사용합니다.

## 프로젝트 구조

- `src/GameController.js`: 상태 전환, 스폰, 공격, 충돌, 승패 판정
- `src/entities/`: 플레이어, 세이렌, 게이트, 무기, 몬스터, 탄환 객체
- `src/input/PointerController.js`: 마우스 및 터치 입력을 레인 위치로 변환
- `src/render/GameRenderer.js`: 배경, 캐릭터, 무기, 전투 연출 Canvas 렌더링
- `src/ui/GameUI.js`: 시작, 실패, 성공 대화상자와 HUD
- `src/config.js`: 공격력, 발사, 동료 합류 및 세이렌 설정
- `assets/game/`: 게임에서 사용하는 이미지

새 동료 기준이나 발사 속도를 조절하려면 `src/config.js`를 수정하세요. 캐릭터 모양과 해변 연출은 `src/render/GameRenderer.js`에서 관리합니다.

## 실행 및 배포

`index.html`을 정적 호스팅에 올리면 됩니다. 로컬에서 확인할 때는 정적 웹 서버를 사용하세요. 게임은 GitHub Pages에서 공개됩니다.
